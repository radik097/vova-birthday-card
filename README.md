# Birthday card for Vova

Static GitHub Pages site. No build step is required.

## Edit text

Open `config.js` and change the values:

- `name`
- `headline`
- `lead`
- `wishes`
- `signature`

## Run locally

Open `index.html` in a browser, or run a simple static server from this folder.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder.
3. In repository settings, open `Pages`.
4. Select deployment from branch.
5. Choose branch `main` and folder `/root`.
6. Save.

The site will be available at the GitHub Pages URL after GitHub finishes deployment.
